# Ymmo — Plateforme Immobilière

Projet UF B2 INFRA & DEV — 

## Description
Plateforme web de gestion de biens immobiliers pour le groupe Ymmo.

## Stack technique
- **Backend** : PHP 8
- **Base de données** : MySQL
- **Frontend** : HTML, CSS, JavaScript, Chart.js
- **Analyse de données** : Python (matplotlib, pandas)
- **Serveur local** : XAMPP

## Fonctionnalités
- Listing des biens avec filtres
- Carousel de photos par bien
- Page statistiques avec graphiques
- Espace agent sécurisé
- Dashboard pour publier des biens
- Script Python d'analyse de données

## Infrastructure
- Windows Server 2025 (AD DS, DHCP, GPO)
- Domaine : ymmo.local
- Routeur OPNsense
- VM Kali Linux (poste agence)
